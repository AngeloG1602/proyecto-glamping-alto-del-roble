# Glamping Alto del Roble — sitio web

Sitio de reservas directas de Glamping Alto del Roble (6 domos con vista a la represa de Guatavita).
La definición completa del proyecto vive en [`/docs`](./docs).

## Desarrollo local

```bash
npm install
npm run dev     # http://localhost:3000
npm run lint
npm run format
```

Etapa actual: **versión local** con datos hardcodeados en `/lib/data` y pago simulado — sin base de
datos, sin Wompi y sin despliegue.
